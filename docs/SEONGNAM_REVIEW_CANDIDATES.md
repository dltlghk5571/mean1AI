**캐시 응답을 바탕으로 작성한 조사 요약**이며 원본 HTML 다운로드나 현행 조직·정책의 최종
검수 결과가 아니다. 사용한 도구는 민원 목록 약 2주, 편람 약 6일 전의 수집 시점을 표시했다.
확인한 사실과 미확인 항목을 분리하고, 검색·학습 이용 상태는 모두 `unknown`으로 남겼다.

이 12개는 확보한 목록에서 고른 첫 후보이며 생활불편·복지 혜택을 충분히 대표하는 완성된
시연 목록은 아니다. 특히 복지 부정수급 신고와 복지 혜택 안내를 같은 기능으로 취급하지 않는다.
편람 목록은 소음 시설 대여의 담당 부서를 구 단위로만 표시하므로 임의의 과·팀을 채우지 않았다.
실제 상세 접수 URL·신청 조건·구비서류·처리기한·금액·유효일은 추가 확인 대상이다.

분류는 세 가지 기준을 섞지 않고 상위 노드로 구분했다.

- 포털 서비스 유형 7개: 문의·상담, 불편개선 요청, 의견제안 등.
- 포털 서비스 분야 8개: 행정, 복지, 도시주택 등.
- 민원편람 분야 13개: 사회복지, 교육·청소년, 보건·위생·환경 등.

총 28개 하위 항목과 구분용 상위 노드 3개다. 원본 코드 값은 확인하지 못해 `source_code=null`이며
SN-*는 프로젝트 내부 ID다. 포털 항목별 분야 값이 화면에서 확인되지 않은 경우 서비스 유형만
연결했다. 편람 분야와 포털 분야의 다대다 대응은 추정하지 않았다.

## 화면에서 이어서 검수하기

1. 담당자로 로그인하고 `/staff/service-catalogs`의 **안내 자료 검수**를 연다.
2. **성남시 조사 후보 12개 불러오기**로 요약을 확인한 뒤 **검수 대기로 등록**한다.
3. 자료별 출처·표시 조직·필요 정보·날짜·이용 조건을 확인한다. 자동 승인되지 않는다.
4. 최신 원문, 상세 절차, 이용 조건을 확인하고 JSON에 근거를 반영한다. 변경된 내용은 새 버전으로
   등록한다. 검색 이용 상태가 전부 allowed인 경우에만 검토 승인 계정이 공개를 진행할 수 있다.
5. 공개할 버전과 전체 교체 범위를 확인하고 날짜·사유·확인 체크 후 승인한다.

검토 승인 역할만 공개·철회할 수 있고, 감사 조회 역할은 읽기만 가능하다. 검색 승인은 학습 사용
승인이 아니다. 승인 후에도 기존 민원 분류용 합성 `departments.json`을 자동으로 바꾸지 않는다.

다음 데이터 작업은 생활불편·복지 혜택의 상세 자료 확보, 조직·관할 대조, 실제 HTML 선택자와
이용 조건 검수다. 네트워크 수집기는 아직 비활성 상태이며 이 JSON은 수동 조사 경로의 산출물이다.

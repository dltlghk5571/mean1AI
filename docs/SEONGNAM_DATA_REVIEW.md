# 공식 자료 검수 작업표

2026-09-09 작성·보완. **2026-09-07에 조사한 로컬 후보의 미해결 항목을 정리**했다.
같은 날 수집기 작업에서 공식 복지 목록·상세 일부와 조직도 DOM을 추가 확인했다.

후보 버전의 최신 조직·정책·이용 조건을 확정하거나 승인하지 않았다.

2026-09-13에는 [가로등·보안등 한 건의 공식 근거 검수](LIGHTING_SOURCE_REVIEW.md)를 추가했다.
직접 GET으로 세 구 담당 업무와 분당구의 일부 동별 표기를 확인했다. 신고서는 본인확인
화면 이후를 열람하지 못했으며, 자료별 이용 범위·전체 시설 관할·필수 항목은 보류다.
이는 새 조사 기록이고 아래 기존 후보·승인 상태·`source-review` 출력은 변경하지 않았다.

같은 날 [도로·보도 파손 한 건의 추가 검수](ROAD_SOURCE_REVIEW.md)에서는 수정구 도로관리·TF의

R04의 수정구 세부 관할은 여전히 미확정이다. RD01~05에 이용 범위·빈 신고서·시행일·실자료
적용 전 확인을 남겼으며, 기존 후보를 수정하거나 검색·학습 이용을 승인하지 않았다.

이어서 RD02를 구청 TF팀 업무표·2026년 업무계획·공식 사업 소식과 대조했다. TF팀의 개설 사업과

계획표의 사업기간과 후속 소식의 기간 차이도 기록했다. R04/RD02의 전체 관할·시설 이관 기준은

대상은 `seongnam-pilot-20260907-v1`이며 [당시 조사 근거](SEONGNAM_PILOT_SERVICES.md)와
[수집·승인 절차](SERVICE_DATA_PIPELINE.md)를 함께 본다.

## 재현 가능한 검수 목록

```powershell
python -X utf8 -m evals.pilot_run source-review
```

이용 조건·HTTP 원문 미확보·게시일 누락, 업무별 시행일·조직 대응·관할 검토 필요를 출력한다.

`live_verification_performed=false`이므로 이 결과는 **검수 할 일 목록**이다.
사용 조건 승인이나 담당자 검토 기록을 대신하지 않는다.

## 기록 양식과 다음 버전

각 항목은 아래 양식으로 새 기록을 남긴다. 실제 확인 전 상태는 `pending`으로 유지한다.

```text
검수 ID / 대상 service_id·source_document_id:
담당 / 검토자:
원본 URL / 실제 확인 시각:
본문에 표시된 업무·문의 담당:
하단 부서 표시 / 확인된 역할과 근거:
정책 기준 연도 / 시행 기간 / 이용 표시 근거:
확인 결과: pending | resolved | blocked
근거와 차이 / 미해결 사유:
다음 데이터 버전 / 변경 해시:
```

확인된 내용은 현재 후보를 덮어쓰지 않고 새 `ServiceBundle.version`으로 작성한다. 요약이 바뀌면
`content_hash`를 다시 계산한다. 실제 HTTP 응답이 없으면 `fetched_at`을 채우지 않고, 게시·수정·
시행일을 조회 날짜로 대신하지 않는다. 검수 UI에 새 버전을 등록하고 사람의 공개 결정을 남긴다.
새 버전도 미확인 자료나 관할이 있으면 해당 경계를 유지한다.

모델 팀은 이 검수가 끝나기 전에 공식 본문을 학습 예시로 변환하지 않는다. 지금은
[별도로 작성한 합성 대화와 평가 도구](PILOT_MODEL_EVALS.md)를 사용해 인터페이스와 정답 기준부터
맞출 수 있다. 조직 대응표를 확보해도 시민에게 수십 개 부서 중 하나를 고르게 하지 않는다.

### 신고 경로와 네 질문의 검수안

SW-S5는 [국민신문고 민원신청](https://www.epeople.go.kr/nep/pttn/gnrlPttn/PttnRqstWrtnInfo.paid)과
통합 운영되며 별도 국민신문고 링크를 제공한다. 페이지의 정부통합인증 관련 안내는 해당 화면에
대한 설명이고 모든 로그인 방식의 성공·실패를 검증한 결과가 아니다. SW-S6은
[안전신문고](https://www.safetyreport.go.kr/)의 도로·시설물 파손 등 범주와 처리기관 지정 절차를
설명한다. 따라서 위험한 시설 상태의 신고 경로 후보로 검토할 수 있지만, 하수도·맨홀의 정확한
선택 항목·분류 코드·최종 처리 부서·신고서 필수 입력을 이 일반 안내만으로 확정하지 않는다.

위 D-S8·9의 09-13 기록에는 안전신문고 신고 본문 미표시와 국민신문고 본인확인 경계가 남아
있다. 이번에는 인증 이후 양식을 다시 시도하지 않았으며 사진 장수·좌표 형식·필수 서류는
미확인으로 유지한다. 공식 접수번호·기관 수신·현장 조치 완료도 확인하지 않았다.

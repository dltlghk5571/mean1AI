# 성남시 민원 업무 프로세스 조사

조사 기준일: 2026-09-05. 현재 개발 중인 서비스와 연결되는 시민 민원 접수, 소관 배정,
검토, 답변, 사후관리를 조사했다. 인사·예산·회계 등 시청의 전체 내부 업무는 범위에 포함하지 않았다.
성남시 안내·시정소식, 성남시의회 회의록, 성남시 작성 운영보고서, 국가법령정보센터를 사용했다.
아래에서 **확인 사실**, **법령 기준**, **앱 설계 제안**을 구분한다.

핵심은 시민이 내용을 제출한 뒤 **접수 확인 → 담당 부서 확인 → 검토·조사 → 답변 통지 →
필요한 조치의 추적**까지 이어지는 경험이다. 답변 등록만으로 실제 불편이 해결됐다고 표시하면
안 된다. 성남시의회 2023-11-23 회의록에도 민원 통계의 답변 완료와 문제 해결을 구분하고,
예정된 사업의 후속 진행 상황을 시민에게 알려야 한다는 논의가 있다.
[성남시의회 제289회 행정교육위원회 회의록](https://sncouncil.go.kr/record/recordView.do?key=cbf9a745fc3f512950d381c8c52264691e7db7852a029c82ade24fe8248accc1d6b8d99955bafe2b)

## 1. 시민이 들어오는 창구와 담당 범위

| 창구·업무 | 공식 자료에서 확인한 내용 | 서비스에 주는 의미 |
| --- | --- | --- |
| 온라인 민원상담 / 성남시에 바란다 | 국민신문고와 통합 운영. 시 안내의 관리 담당은 소통관 소통지원팀이다. [현재 서비스 안내](https://www.seongnam.go.kr/pm02020101?curPage=1) | 앱에 저장한 번호와 국민신문고의 공식 접수번호를 구분해야 한다. 현재 데모 제출은 실제 시청 접수가 아니다. |
| 시장에게 바란다 바로문자 | 해당 부서가 검토·답변하고 소통관실이 답변을 재확인하며 사후관리를 총괄한다. 2026-06-19 운영 설명이다. [성남시 시정소식](https://snvision.seongnam.go.kr/22943) | 채널에 따라 담당 부서 검토 뒤 추가 확인 단계가 필요하다. 이 절차를 모든 채널에 일괄 적용할 근거는 확인하지 못했다. |
| 전화 상담·당직 | 성남콜센터는 평일 09:00~18:00 운영하고 상담시간 외에는 당직실로 연결한다. 조직도에는 당직민원인 새올 상담민원 관련 업무가 명시돼 있다. [성남시 조직·상담 안내](https://www.seongnam.go.kr/pm04041101?deptCode=37802890000&orgSelect=orgSelect01) | 시민의 직접 작성 외에 상담원·당직자의 대리 입력, 인계와 연락 이력이 필요할 수 있다. 실제 입력·인계 방식은 추가 확인 대상이다. |
| 증명 발급 등 법정민원 | 어디서나민원은 가까운 창구 또는 정부24 등에서 신청하고, 증명기관과 수령 창구를 거쳐 문서를 교부하는 구조다. [성남시 어디서나민원 안내](https://www.seongnam.go.kr/city/1000071/10046/contents.do) | 증명서·허가 신청은 서식, 구비서류, 수수료 등이 달라 생활불편 자유서술 폼과 별도 경로가 필요하다. |
| 시민고충처리위원회 | 시 서비스 안내의 담당은 감사관 조사2팀. 2024년 운영보고서는 상담·접수, 조사 여부 결정, 조사개시 통보, 자료·현장 조사, 의결, 결과 통지를 설명한다. [현재 서비스 안내](https://www.seongnam.go.kr/pm02020101?curPage=1), [위원회 운영보고서 11~12쪽](https://m.acrc.go.kr/boardDownload.es?bid=1020&list_no=88176&seq=1#page=11) | 위법·부당한 행정 등에 대한 고충의 독립 조사 경로다. 일반 담당 부서의 답변 검토 화면만으로 대체할 수 없다. |
| 시민 제안 | 창의적인 행정 개선 아이디어를 받는 별도 서비스이며 소통관 소통혁신팀이 담당한다. [성남시 서비스 안내](https://www.seongnam.go.kr/pm02020101?curPage=1) | 생활불편 해결 요청과 정책 아이디어를 구분해 적절한 접수 경로를 안내한다. |

성남시에 바란다 기존 안내는 2017-11-23 국민신문고 통합 이후 시 홈페이지 인증과 국민신문고
인증이 연동되지 않는다고 설명한다. 현재 데모의 쿠키·조회 코드를 실제 국민신문고 본인 확인으로
설명해서는 안 된다. 정식 도입 시 적용할 인증 방식과 연계 계약·인터페이스는 별도 확인이 필요하다.
[성남시에 바란다 이용 안내](https://www.seongnam.go.kr/mayor/epeopleHope.do?menuIdx=1001318&returnURL=%2Fmain.do)

구 새올 전자민원 공개상담 화면은 해당 화면의 신규 상담 접수를 종료하고 성남시에 바란다로
안내한다. 이는 새올 내부 업무 전체가 폐지됐다는 뜻이 아니다. 공개상담의 개인정보 확인과
비공개 민원의 본인 조회를 구분하는 안내도 있다.
[성남시 새올 전자민원 상담 안내](https://eminwon.seongnam.go.kr/emwp/gov/mogaha/ntis/web/emwp/cns/action/EmwpCnslWebAction.do?context=NTIS&jndinm=EmwpCnslWebEJB&menu_id=EMWPCnslWebInqL&method=selectCnslWebPage&methodnm=selectCnslWebPage)

## 2. 접수 이후 실제 업무 흐름

아래 표는 공개된 채널 운영 설명과 공통 법령을 합쳐 정리한 업무 단계다. 성남시 내부 시스템의
실제 화면명·상태 코드·결재선을 그대로 옮긴 것은 아니다.

| 단계 | 확인된 업무 | 앱에서 필요한 기록·동작 — 설계 제안 |
| --- | --- | --- |
| 제출·접수 | 전자민원은 소관 행정기관의 전자민원창구 도달 후 8근무시간 이내 접수. 접수 시 구비서류, 절차, 예상 기간 등을 안내한다. [시행령 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031678561) | 제출 시각, 외부 전달 시각, 공식 접수 시각·번호를 별도로 저장. 공식 접수 응답 전에는 전달 상태를 정확히 표시. |
| 소관 확인·배정 | 민원실에서 주무부서로 보내거나 다른 기관 소관이면 이송한다. 전자문서는 지체 없이 전자적으로 이송한다. [시행령 제13조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0013&lsiSeq=285815&urlMode=lsScJoRltInfoR) | 최초 배정, 재배정, 기관 이송, 사유, 받는 부서의 확인, 시민 안내 이력. AI 추천과 사람의 배정 확정을 구분. |
| 내용 검토·보완 | 보완이 필요하면 기간을 정해 요청한다. 민원인은 원칙적으로 종결 전 보완·변경·취하할 수 있으며 법률·민원 성질에 따른 예외가 있다. [법 제22조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0022&lsiSeq=239293&urlMode=lsScJoRltInfoR) | 부족한 자료, 요청 사유, 보완 기한, 추가 제출 및 변경 이력. 민원인의 추가 제출 화면. |
| 조사·협의·기간 관리 | 고충민원의 현장 조사, 관계 기관 협조, 처리기간 연장·진행 통지에 관한 별도 규정이 있다. [시행령 제17~23조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=58484) | 현장 확인 및 협의 요청·회신, 기한 계산 근거, 연장 사유·동의·통지, 다음 안내일. |
| 답변 확정·통지 | 처리결과는 원칙적으로 문서 통지하며 정해진 경우 다른 방식이 허용된다. 바로문자는 소통관실의 답변 재확인이 확인된다. [법 제27조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0027&lsiSeq=239293&urlMode=lsScJoRltInfoR), [바로문자 운영 설명](https://snvision.seongnam.go.kr/22943) | 내부 검토, 채널별 추가 확인, 시민용 답변 확정, 발송·전달 성공을 각각 기록. 초안 생성만으로 통지하지 않음. |
| 후속 조치 | 바로문자 운영에는 사후관리가 포함된다. 의회 회의록은 답변과 실제 조치의 구분 필요성을 보여준다. [바로문자 운영 설명](https://snvision.seongnam.go.kr/22943), [시의회 회의록](https://sncouncil.go.kr/record/recordView.do?key=cbf9a745fc3f512950d381c8c52264691e7db7852a029c82ade24fe8248accc1d6b8d99955bafe2b) | 조치 필요 여부, 계획, 예정일, 진행 내용, 담당자 확인, 조치 완료 근거, 시민의 추가 의견. |

바로문자의 구체적인 접수 안내는 2023-12-19 자료에도 나온다. 접수 확인 문자, 담당 부서·처리기한
지정, 기한 내 처리하기 어려운 경우 안내, 답변 담당자 이름·연락처, 장기 정책 제안의 별도 관리가
당시 운영 방침이었다. 2026년 자료는 부서 검토와 소통관 재확인·사후관리를 다시 확인해 주지만,
2023년의 모든 세부 운영 항목이 현재도 동일한지는 확인이 필요하다.
[성남시 바로문자 운영 개선 설명, 2023-12-19](https://snvision.seongnam.go.kr/18320)

따라서 내부 계정·감사 식별자와 시민에게 안내하는 공식 업무 연락처도 구분하는 편이 맞다.
향후 담당 부서가 승인한 공개 연락 정보를 별도 필드로 관리하고, 현재 데모의 로그인 계정을
시민 답변의 담당자 정보로 노출하지 않는 설계를 제안한다.

## 3. 처리기한은 민원의 종류에 따라 다르다

법령 확인본은 민원 처리에 관한 법률의 2022-07-12 시행본과 시행령의 **2026-05-06 시행본**이다.
검색에 함께 노출된 법률 제21728호는 **2026-12-03 시행 예정**이므로 조사일의 적용 기준과 구분했다.
[국가법령정보센터 시행 예정 법률](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=286421)
다음은 공통 기준이며, 개별 법령의 특별 규정과 해당 기관이 정한 적용 기준을 함께 확인해야 한다.
현장 수리·공사의 완료 약속과 행정상 민원 처리기한을 같은 날짜로 간주하면 안 된다.

| 법적 민원 종류 | 공통 처리기간 | 적용 시 주의점 |
| --- | --- | --- |
| 법령 설명·해석을 요구하는 질의 | 특별한 사유가 없으면 14일 이내 | 생활 분야가 아닌 요구의 성격으로 구분 |
| 제도·절차 등 법령 외 질의 | 특별한 사유가 없으면 7일 이내 | 모든 생활민원에 7일을 적용하는 근거가 아님 |
| 건의민원 | 특별한 사유가 없으면 14일 이내 | 구체적 요구의 성격을 검토 |
| 기타민원 | 특별한 사유가 없으면 즉시 | 기관 특성에 따른 별도 기간·절차 운영 가능. 즉시는 정당한 사유가 없으면 3근무시간 이내 |
| 행정기관에 접수된 고충민원 | 특별한 사유가 없으면 7일 이내 | 현장 조사와 그 기간의 불산입 등 별도 규정 존재 |
| 법정민원 | 민원 종류별 공표 기간 | 민원편람·개별 법령 확인. 서식 업무별 설정 필요 |

근거: [시행령 제14~20조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=58484),
[법 제17조 — 법정민원 처리기간](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=239293&urlMode=lsScJoRltInfoR).
법은 법정·질의·건의·기타·고충을 구분하므로, 앱의 교통·환경·복지 같은 **내용 분야와 법적 유형을
별도 분류**해야 한다.
[법 제2조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0002&lsiSeq=239293&urlMode=lsScJoRltInfoR)

성남시 시민고충처리위원회의 **2024년 운영보고서**는 접수 후 30일 내 조사 완료와 연장 가능성을
안내한다. 이 별도 위원회 절차에 위 표의 고충민원 7일을 그대로 적용하면 안 된다. 보고서는 당시
운영 근거이며, 2026년 적용 기간·연장 절차는 최신 조례·시행규칙과 담당 부서 확인이 필요하다.
[위원회 운영보고서 11~12쪽](https://m.acrc.go.kr/boardDownload.es?bid=1020&list_no=88176&seq=1#page=11)

기한 계산과 예외에서 구현에 영향을 주는 기준은 다음과 같다.

- **근무일 계산:** 5일 이하는 접수시각부터 근무시간으로 계산하며 1일은 8시간이다. 6일 이상은
  첫날을 포함해 일수로 계산한다. 두 경우 모두 토요일·공휴일은 제외한다. 주·월·연으로 정한
  기간은 별도 규칙을 적용한다. [법 제19조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0019&lsiSeq=239293&urlMode=lsScJoRltInfoR)
- **부서·기관 이송:** 민원실에서 주무부서로는 원칙 1근무시간, 특별한 사유가 있으면 3근무시간.
  같은 기관 내 잘못 접수한 부서는 민원실을 거쳐 3근무시간, 다른 기관 소관은 8근무시간 이내
  이송과 민원인 통지가 기준이다. 전자문서는 별도로 지체 없이 전자 이송하며, 사전 안내한
  홈페이지 공개로 통지를 생략할 수 있는 경우가 있다. [시행령 제13조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0013&lsiSeq=285815&urlMode=lsScJoRltInfoR)
- **연장:** 기관·부서 협조, 사실·현장 확인, 불가항력 등의 사유로 원래 처리기간 범위에서
  한 차례 연장할 수 있다. 다시 연장하려면 민원인 동의가 필요하며 원래 처리기간 범위에서
  한 차례만 가능하다. 사유와 처리완료 예정일을 지체 없이 문서로 통지한다. 2026년 개정은
  단순 업무과중, 담당자 지정 지연·부재를 연장 사유로 금지한다. [시행령 제21조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1025225383)
- **진행 통지:** 접수 후 30일이 지나도 미완료이거나 민원인이 명시적으로 요청하면 진행 상황과
  예정일을 알린다. 원칙적으로 30일마다 통지하며, 홈페이지 등 진행 공개를 사전에 안내한 경우
  생략 가능한 규정도 있다. [시행령 제23조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033041001)
- **보완 기한:** 민원인이 보완기간 연장을 요청하는 절차는 기관의 처리기간 연장과 별개다.
  따라서 보완 요청·제출·기간 변경을 독립 기록으로 관리해야 한다. [시행령 제24조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0024&lsiSeq=285815&urlMode=lsScJoRltInfoR)

설계에서는 기한 계산 규칙의 출처·시행일, 적용 유형, 산입 제외 기간, 연장 승인·동의와 통지
이력을 보관해야 한다. AI가 유형을 추정했다는 이유만으로 공식 기한을 확정하거나 변경하지 않는다.

## 4. 부서 배정과 협의

성남시 행정기구 및 정원 조례 시행규칙의 2026-04-22 시행본에는 같은 실·국·소·구청 내 부서 간
소관 이견을 해당 실·국·소장 또는 구청장의 지시·조정으로 정하는 규정이 있다. 부서가 서로
소관이 아니라고 판단하는 상황에 별도의 조정 절차가 필요하다는 근거다.
[성남시 행정기구 및 정원 조례 시행규칙](https://www.law.go.kr/ordinLinkProc.do?chrClsCd=&mode=20&ordinNm=%EC%84%B1%EB%82%A8%EC%8B%9C%ED%96%89%EC%A0%95%EA%B8%B0%EA%B5%AC%EB%B0%8F%EC%A0%95%EC%9B%90%EC%A1%B0%EB%A1%80%EC%8B%9C%ED%96%89%EA%B7%9C%EC%B9%99)

앱에는 다음 판단 자료와 업무를 두는 것을 제안한다.

- 민원 분야·세부 요구, 발생 위치, 시설의 관리 주체, 현행 업무분장 근거를 함께 검토.
- 주관 부서와 협조 부서를 구분하고, 기관 밖 이송은 내부 재배정과 구분.
- 소관 이견의 요청 사유, 조정 담당자, 결정 근거, 최종 인계 이력을 기록.
- 부서·관할 자료의 시행일과 버전을 보관하고 조직개편 시 기존 민원에 대한 재확인 절차 마련.

현재 카탈로그는 버전과 근거를 기록하는 **합성 데모 업무분장**이다. 이번 조사에서 발견한
조직명 몇 개를 대입하는 것만으로 공식 배정 엔진이 되지는 않는다. 실제 업무분장 별표, 시설
관리 주체, 기관 간 협약, 전결 범위를 확인한 뒤 별도 승인 자료로 구성해야 한다.

## 5. 시민 화면과 담당자 화면의 설계 제안

시민 메인은 **민원 제출**, **내 민원 확인**, **업무·신청 방법 찾기**를 중심에 둔다.
시민에게 처리 부서를 먼저 고르게 하기보다는 생활 분야·발생 위치·원하는 조치를 쉽게 입력하게
하고, 법적 유형과 소관은 담당자가 확인한다. 증명서·허가·위원회 신청은 적절한 별도 창구로 안내한다.

하나의 진행률 대신 서로 다른 사실을 구분해 보여주는 상태 모델을 제안한다. 아래 명칭은
성남시 공식 상태 코드가 아니라 향후 앱 설계를 위한 예시다.

| 구분 | 표시 예시 | 필요한 조건 |
| --- | --- | --- |
| 전달·접수 | 제출됨 → 전달 중 → 기관 접수 확인 | 실제 연계 수신·접수 확인에 근거. 데모는 데모 접수임을 명시 |
| 검토·답변 | 담당 부서 확인 중 → 검토 중 → 답변 등록 | 보완 요청, 협의, 기간 변경은 별도 사건으로 표시 |
| 실제 조치 | 조치 필요 여부 확인 중 / 조치 계획 / 조치 진행 / 조치 완료 확인 / 추가 조치 없음 | 담당자 판단·설명·증빙과 연결. 모든 질의민원이 현장 조치를 필요로 하지는 않음 |

시민 상세 화면에는 현재 담당 부서, 답변 예정일과 산정 근거, 변경 사유, 보완 요청에 응답하는
동작, 확정 답변, 후속 조치와 다음 안내일이 필요하다. 실제 연계·운영 규칙이 확정되기 전에는
예상 처리일이나 부서를 사실처럼 미리 표시하지 않는다.

담당자 화면은 업무별 대기열이 필요하다. 접수·배정 대기, 소관 협의, 보완 회신 대기, 답변 검토,
기한 임박·경과, 통지 실패, 사후 조치 대기를 구분하는 구성이 적합하다. 채널별로 검토·추가 확인
규칙을 적용하고 실제 승인 권한은 업무분장·전결 규정에 맞춘다.

AI의 역할은 요약, 민감·긴급 신호 표시, 분류·부서 후보 추천, 확인 질문, 근거 검색과 답변 초안이다.
공식 배정 확정, 기한 연장 판단, 외부 통지, 답변 승인과 조치 완료 확인은 권한 있는 사람의
판단과 기록을 거치도록 설계한다. 유사 민원 탐지는 참고 정보로 제공하며 자동 반려·종결에 쓰지 않는다.

## 6. 현재 구현과의 차이 및 우선순위

비교 대상은 조사일의 작업 폴더다. 현재 시민 공개 상태는 `접수 완료 / 확인 중 / 답변 등록`이며,
공개 답변은 내부 검토와 분리된 명시적 발행 및 불변 이력으로 관리한다.
`Complaint.channel`과 합성 카탈로그 버전 관리도 이미 존재한다.

| 우선순위 | 현재 구현 | 다음 설계 과제 |
| --- | --- | --- |
| P0 | 시민 제출·번호 조회·본인 접근, 담당자 대기열이 연결됨 | 시민 상세의 업무 타임라인과 추가 제출 경로를 정의 |
| P0 | 분야·세부 유형과 후보 부서 추천, 합성 업무분장 근거 있음 | 법적 민원 유형을 별도로 두고 관할 확인·인계·소관 협의·협조 요청을 정의 |
| P0 | 업무 처리기한과 연장·보완 사건 모델 없음 | 근무일 계산, 규칙 버전, 기한 산정 확인, 연장 동의·통지와 보완 회신 설계 |
| P0 | 내부 검토와 시민용 답변 공개가 분리됨 | 답변 등록 뒤 실제 조치 추적, 다음 안내일, 시민 추가 의견을 연결 |
| P1 | `channel`은 있으나 외부 민원 시스템 접수 확인·발송 연계 없음 | 외부 기관·접수번호·시각 매핑, 중복 전송 방지, 통지 재시도와 성공 확인 |
| P1 | reviewer 역할이 답변을 공개 | 채널별 추가 확인과 실제 전결 권한 모델, 승인된 공식 업무 연락처 |
| P1 | 사진·지도·실명 인증·문자 알림 미구현 | 위치·사진 증빙, 필요한 인증·통지 수단, 개인정보 보관·접근 정책 확정 |
| P2 | 분류·검토 중심의 운영 정보 | 기한 내 답변율, 이송 횟수, 보완 대기, 사후 조치 이행률을 분리 측정 |

제안하는 다음 설계 묶음은 **시민의 진행 확인·보완 제출 화면 + 담당자의 배정·기한·사후 조치
화면**이다. 생활민원 한 건이 접수에서 후속 확인까지 이어지는 대표 시나리오를 먼저 완성하고,
법정민원과 위원회 민원은 각각의 절차를 검증한 뒤 확장한다.

## 8. 자료 사용과 산출물 범위

현재 안내와 시행 법령을 우선 사용하고, 2023년 의회·바로문자 자료 및 2024년 위원회 보고서는
해당 시점의 운영 근거로 표시했다. 일부 구 홈페이지·자치법규 페이지는 검색 색인에서는 내용이
확인되지만 본문 재조회가 원활하지 않았다. 이들 자료로 최신 내부 전산 절차를 단정하지 않았다.

이번 산출물은 조사·설계 문서다. 앱 코드, 합성 부서 카탈로그와 운영 데이터는 변경하지 않았고,
외부 기관에 민원을 제출하거나 메시지를 보내지 않았다. 실제 시민의 민원 본문·개인정보는
문서나 테스트 데이터로 복사하지 않았다.

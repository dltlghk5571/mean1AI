# 성남 민원 AI · 구현 현황

2026-09-15 · 앱 기준 커밋 `1a45d4feaf8bdb9d2815108089f45fbbda5ae43d`

**시민의 대화·내부 접수·담당자 검토·답변 조회를 위한 시제품과 모델 연결부가 구현돼 있다.**
실제 동아리 LLM, 검수한 성남 업무 자료의 운영 적용, 공식 기관 접수, 사용자 효과 측정은 남아 있다.
현재 사용자 요청에 따라 모델 서버 연결을 보류한다.

## 무엇을 만들고 있는가

부서명과 복잡한 서식을 몰라도 자기 상황을 말하면 필요한 안내를 받거나 민원을 준비하고,
확인·접수·진행 조회까지 할 수 있는 시민 중심 서비스다. 담당자에게는 정보 보완과 같은 현장의
반복 처리를 줄일 도구를 제공한다. 목표 기준은 [GOALS.md](../GOALS.md)에 있다.

| 중간목표 | 현재 확보한 것 | 아직 입증하지 못한 것 |
| --- | --- | --- |
| G1 쉬운 시민 이용 | 시민 화면·대화 단계·수정·사진·내부 접수·조회와 자동 검사 | 실제 참여자의 자력 완료, 보조기기·실기기 사용성 |
| G2 성남 업무에 맞는 근거 | 공식 출처 조사, 업무·부서·관할·질문 후보, 검수·공개 도구 | 최종 승인된 실제 소관표와 제품에 적용한 자료 |
| G3 두 LLM의 협업 | 대화·추출·분류·사건 비교 JSON 계약과 앱 연결부 | 실제 모델 추론·학습·정확도·지연 측정 |
| G4 담당자 반복 업무 감소 | 보완 문의·답변 공개·공통 현장 사건 관리 | 실무자 검증과 기존 방식 대비 업무 절감 |
| G5 전체 효과 입증 | 자동 회귀 검사와 합성 시연 기록, 평가 계획 | 실제 모델·자료·참여자를 포함한 통합 결과 |

## 지금 구현된 기능

여기서 '구현'은 시제품 코드와 검증 근거가 있다는 뜻이며, 서비스 운영이나 실사용 효과의
완료를 뜻하지 않는다. 자세한 전체 목록은 [README](../README.md)에 있다.

| 영역 | 현재 동작 | 범위·근거 |
| --- | --- | --- |
| 시민 진입 | 홈, 대화형 접수, 직접 작성. 홈에서 고른 도로·가로등·무단투기·놀이터 상황으로 새 대화 시작 | 기존 초안은 보존하고 초기화 동의 후 새로 시작. [UI](UI.md) |
| 대화 진행 | 목적 선택, 내용·장소, 상황별 추가 질문, 모름·건너뛰기, 답변 수정·이어보기 | 12개 상황·앱에서 작성한 추가 질문 24개. [질문 흐름](CITIZEN_QUESTIONS.md) |
| 입력 정리 제안 | 원문 인용과 목적·상황·장소·답변을 확인하는 카드, 적용·거절·수정 | 연결부·UI 구현. 기본 `off`, `demo`는 표시된 합성 문장 한 건. 실제 LLM 추출 아님. [추출 계약](CHAT_EXTRACTION.md) |
| 정보 안내 | 검수된 로컬 자료 검색·필요 정보 조회·출처 카드·근거 부족 안내 | 기본 `agent_demo`는 시연 제공자. 실제 정책 상담 정확도 미측정. [도구 계약](AGENT_API.md) |
| 사진·접수 | 사진 최대 3장 선택·미리보기·삭제·검사, 본문과 사진 확인 후 명시적 동의로 내부 저장 | 사진 AI 판독·기관 제출 없음. [사진](CITIZEN_PHOTOS.md), [접수 API](CHAT_API.md) |
| 내 민원 | 접수번호·조회 코드, 권한이 있는 본인 기록·사진·공개 답변 조회, 추가 문의 | 내부 접수번호이며 국민신문고·성남시 공식 접수번호가 아님. [시민 API](../app/api/citizen.py) |
| 담당자 처리 | 업무 목록·검토·배정·답변 초안 승인, 시민 답변 별도 공개, 미답변 문의 확인 | 데모 역할 계정 기반. 실제 기관 인증·업무 시스템 미연결. [README](../README.md) |
| 같은 현장 관리 | 유사 후보 확인, 사건 생성·연결·분리·진행과 공통 안내 공개·철회 | 개별 민원·답변 보존, 담당자 확인 필수. LLM 관계 비교는 선택적 연결부. [공통 사건](SHARED_INCIDENTS.md) |
| 자료 관리 | 출처·조직·업무·질문 JSON, HTML 추출·대조 보고서, 검수·승인·공개·철회 | 수집 도구와 조사 후보가 실제 자료 적용 완료를 뜻하지 않음. [자료 흐름](SERVICE_DATA_PIPELINE.md) |
| 모델 연결 | 네 API 작업과 두 모델 역할, 응답 검증·제한 시간·오류 처리·분류 큐 | 가중치 로딩·실제 추론 구현 없음. [모델 API](MODEL_GATEWAY.md) |

| 접근·저장 보호 | CSRF·세션·버전·조회 권한 검사, 재시도 중복 저장 방지, 감사 이력, 식별자 형식 마스킹 | 이름·사진·문맥까지 완전 익명화하는 기능은 아님. [마스킹](../app/services/pii.py) |

## 데이터는 어디까지 준비됐는가

| 자료 | 현재 규모·상태 | 해석할 때 주의할 점 |
| --- | --- | --- |
| 대표 업무 조사 후보 | 생활불편 8개·복지 4개, 조직 표시 47개·업무분장 후보 32개·질문안 44개 | 전체 성남 민원 분류나 승인된 부서 코드 목록이 아님 |
| 업무별 공식 자료 대조 | 9/12개 업무의 공개 자료 검토 이력 | 자료별 이용 범위·적용 시점·관할·최종 승인 대기. 조사 진척을 제품 완성도로 표시하지 않음 |
| 앱 질문 | 12개 상황의 추가 질문 24개 | 공식 법정 필수 서류 24종이라는 뜻이 아님 |
| 기존 pilot 평가 초안 | 합성 100건·50가족, train 24 / dev 24 / test 52 | 공개된 `draft` 정답. 독립 gold나 실제 모델 평가 결과가 아님 |
| 규칙·검색 평가 | 규칙 파이프라인과 로컬 검색의 합성 회귀 검사 | LLM 성능이나 최신 공식 안내의 정확도와 구분 |

근거: [대표 업무](SEONGNAM_PILOT_SERVICES.md), [공식 자료 검수표](SEONGNAM_DATA_REVIEW.md),
[pilot 평가](PILOT_MODEL_EVALS.md), [규칙 평가](EVALS.md).

첨부 가이드는 독립 평가셋을 준비할 때 참고할 수 있다. 다만 작성 모델의 입출력과 검증 모듈은
현재 저장소와 다르다. 계약·준비 여부·입력 범위·개인정보·평가 독립성의 조정안을
[가이드 검토](CHAT_EVAL_GUIDELINE_REVIEW.md)에 정리했다. 새 gold 데이터나 학습기는 만들지 않았다.

## 확인한 검증과 남은 검증

앱 기준 커밋의 [GitHub CI 결과](https://github.com/dltlghk5571/mean1AI/actions/runs/34933357642)를
2026-09-15 다시 확인했다. `test`, `browser`, `gitflow`가 모두 성공했다. 전체 pytest,
Chromium 시나리오, Ruff·서식·mypy, 규칙·검색 평가와 pilot 구조 검사가 포함된다.
이번 현황 정리를 위해 로컬 서버를 시작하지 않았다.

실제 LLM의 정확도·안전 응답·응답 시간, 시민의 과제 성공·도움 요청·소요시간,
담당자의 보완 질문·재분류·현장 처리 감소, 정식 기관 수신 확인은 **미측정 또는 미연결**이다.
실제 사용성 참여자는 아직 확보되지 않았고 5~8명은 모집 계획이다.

## 다음 순서

1. 정식 서식의 항목 순서로 [일반부 제안서 원고](PROJECT_PROPOSAL.md)를 정리했다.
   팀명을 확정하고 [공고·제출 기준](CONTEST_SUBMISSION_NOTES.md)에 따라 HWPX 편집·최종 검수를 한다.
2. 서버 없이 진행할 제품 작업은 '정보 안내 선택 후 질문해도 목적을 다시 묻지 않는 흐름'이다.
   현재 코드의 의심 경로를 재현하고 선택 보존에 필요한 변경으로 한정한다.
3. A·C·D가 평가 대상 계약과 준비 여부·입력 범위를 합의한다. 기존 공개 pilot과 새 독립 시험의
   역할을 정하고, B가 추가 질문·모름·정정 문구를 함께 검토한다.
4. 실제 모델·자료·참여자 조건이 준비되면 생활민원 한 건을 시민 입력부터 담당자 답변·조회까지
   연결해 측정한다. 전체 업무 조사 완료를 먼저 기다리지 않는다.

현재 일정과 의존성은 [TASKS](../TASKS.md)에서 관리한다. 소목표별 종료 후 G0의 시민 전체 흐름으로
돌아오며, 새 연결부·조사 목록·평가 플랫폼을 계속 늘리는 것을 진척으로 삼지 않는다.

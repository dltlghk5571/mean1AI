# 업무 화면 사용성과 검증

## 목록

- 상태 필터는 서버가 선택한 상태의 최근 30건을 불러옵니다. 전체 접수 통계는 전체 DB 기준입니다.
- 검색과 정렬은 현재 불러온 목록에만 적용합니다. `0 / 11건`은 현재 목록 11건에서 일치하는
  항목이 없다는 뜻이며, 이전 접수 건까지 DB 전체를 검색했다는 뜻이 아닙니다.
- 검색 범위는 비식별 제목·위치·분야·세부 유형입니다. Unicode NFKC, 소문자 변환 후 공백으로
  나눈 검색어가 모두 포함되는 행만 표시합니다. 민원 원문이나 추가 개인정보를 요청하지 않습니다.
- 기본 정렬은 서버의 최신 접수순입니다. 오래된순은 그 역순이고, 검토 우선순은 긴급 검토 →
  검토 대기 → 접수됨 → 배정 완료 → 검토 완료입니다. 같은 상태는 최신순을 유지합니다.
- `/`는 입력란·선택 상자·편집 영역·열린 대화상자 밖에서 검색창으로 이동합니다.
  검색창의 `Esc`, 지우기 버튼, 검색 초기화 버튼은 검색어만 지우고 현재 정렬은 유지합니다.
- 검색어는 메모리에만 존재합니다. URL, localStorage, sessionStorage, 서버에 기록하지 않습니다.
- 검색 결과가 없는 행은 native `hidden` 상태를 CSS에서도 보장해 화면과 키보드 탐색에서 제외합니다.
  표시 건수는 스크린 리더에도 짧은 지연 후 전달됩니다.

## 상세와 모바일

상세 구간 링크는 일반 URL fragment 이동입니다. JavaScript가 없어도 이동할 수 있고 고정 메뉴가
본문을 가리지 않도록 여백을 둡니다. 업무분장 버전, 분류 근거와 후보 설명은 줄바꿈해 읽을 수
있습니다. 후보 선택은 검토 승인 역할에서만 가능하며 `aria-pressed`로 선택 상태를 알립니다.

적용 중인 안전 기준은 설명 목록으로 표시합니다. 담당자가 실제로 확인하지 않은 체크박스를
미리 체크하지 않습니다. 내부 승인 전 확인 대화상자, 역할 검증, 개인정보 검사, 감사 이력은
기존 서버 절차를 그대로 사용합니다. 행정 결정·종결·발송 기능은 없습니다.

900px 이하에서는 모바일 메뉴를 사용합니다. 닫힌 메뉴는 `inert`, 열린 동안 본문은 `inert`로
설정합니다. Tab과 Shift+Tab은 메뉴 안에서 순환하며 Esc/닫기 후 열기 버튼으로 포커스를
돌려줍니다. 900px를 넘나들면 메뉴 상태를 초기화합니다.

## 정확한 검증 명령

저장소 루트의 PowerShell에서 실행합니다.

```powershell
$env:AI_PROVIDER='rules'
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m mypy app evals tests
.venv\Scripts\python.exe -m pytest
node --check app/static/app.js
git diff --check
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

브라우저 검증은 `http://127.0.0.1:8765/`에서 합성 계정과 합성 민원만 사용합니다.

1. 기존 합성 목록에서 존재하지 않는 검색어를 입력합니다. 건수가 0이고 행은 화면과 키보드
   탐색에서 사라져야 합니다. 초기화 후 같은 개수의 행이 복원되고 검색창이 포커스를 받습니다.
2. `가로등`을 검색해 일치하는 제목·위치·분야만 남는지 봅니다. 필터 상태에서 오래된순으로
   바꾸면 현재 결과만 역순이어야 합니다. Esc로 지운 뒤에도 정렬은 유지되어야 합니다.
3. 입력란 밖에서 `/`로 검색창에 이동합니다. 선택 상자, 답변 초안, 열린 모달에서 `/`를
   입력해도 검색창으로 포커스를 빼앗기지 않아야 합니다.
4. 390×844, 768×900, 1024×900, 기본 데스크톱에서 목록과 상세의 가로 넘침이 없는지 확인합니다.
   상세 구간 링크로 이동한 본문 제목이 고정 메뉴 아래에서 보여야 합니다.
5. 모바일 메뉴 열기 → Shift+Tab/Tab 순환 → Esc를 확인합니다. 닫힌 메뉴에 보이지 않는
   포커스가 들어가거나, 열린 메뉴 뒤 본문으로 포커스가 빠지면 실패입니다.
6. 합성 예시 입력, 취소, 답변 미리보기, 후보 선택 후 승인 확인창에서 취소를 확인합니다.
   단순한 미리보기·후보 선택·취소는 서버 기록을 변경하지 않아야 합니다.
7. 감사 조회 계정은 후보 버튼과 초안 수정·승인을 사용할 수 없어야 합니다. 브라우저 console에
   오류가 없어야 합니다. 마지막으로 임시 viewport 변경을 해제합니다.

이 절차는 로컬 화면 회귀 확인이며, 공식 접근성 인증이나 보조기기 전체 조합 검증은 아닙니다.
